 

## Background:

-  Add _"fine-art-specific fields like __`artEdition`__, __`artMedium`__, __`artist`__ (as a __`Person`__ entity), or __`isPartOf`__ for print series. These are _[_Schema.org_](http://schema.org/)_ __`VisualArtwork`__ type properties."_

-  Artwise sells works of fine art (originals and limited-edition prints), but the storefront currently describes every product to search engines and crawlers only as a generic [Schema.org](https://Schema.org) `Product`. There is no markup conveying that a product is an artwork, who the artist is, the medium, the edition size, or whether it belongs to a print series.

 

## Necessary Info

-  Currently the product JSON-LD is generated by Shopify's built-in `structured_data` Liquid filter in `snippets/product.liquid` (~line 914), which outputs a `Product` (no variants) or `ProductGroup` (has variants) node and **cannot be extended in place** — there is no way to inject extra properties into the filter's output.

-  Keep the existing `Product` schema untouched and **add a supplemental, linked ****`VisualArtwork`**** JSON-LD block** on the product page, populated from product metafields, so the fine-art semantics are exposed to search engines and other structured-data consumers (general SEO, AI/LLM crawlers).

-  **`VisualArtwork`**** is NOT a Google rich-result type.** Google's rich-results parser does not consume the full [Schema.org](https://Schema.org) vocabulary, so this will **not** produce a new rich snippet on its own. The value is accurate semantic markup for SEO and non-Google consumers. Set client/stakeholder expectations accordingly. (Per [Schema.org](https://Schema.org) docs and Shopify community guidance — see Dev Notes references.)

 **Map directly to standard **[**schema.org/Product**](https://schema.org/Product)** properties (Google reads these for rich results):**

|  **Product Metafield** |  **JSON‑LD property** |
| --- | --- |
|  Artist Name: product.ArtistFancy - single line text |  `brand` → `{ "@type": "Brand", "name": "Jean‑Michel Meurice" }` (and/or `VisualArtwork.artist`) |
|  Color: product.Color - multi-line text |  `color` |
|  Print Type / Medium: product.Type - single line text |  `material` (and `VisualArtwork.artMedium`) |
|  condition: product.Condition - single line text |  `offers.itemCondition` → must be a URL enum, e.g. [`https://schema.org/NewCondition`](https://schema.org/NewCondition) |
|  Year: product.Year - integer |  `VisualArtwork.dateCreated` |
|  Image Size: product.Image_Size - single line text |  `width` / `height` (best split into two numeric values, e.g. `{ "@type":"QuantitativeValue","value":24,"unitCode":"INH" }`) |
|  Subject: product.Subject |  `about` or `keywords` |
|  Style: product.Style |  `VisualArtwork.artform` or `genre` |

 

## Constraints / Scope:

-  **IN scope:** one supplemental `VisualArtwork` JSON-LD block on the product page, populated from product metafields.

-  **OUT of scope:** modifying or replacing the existing `{{ product | structured_data }}` output; collection/article/other-template schema

-  **Assumption:** these products are fine art and should carry `VisualArtwork`. If the catalog also contains non-art items (gift cards, framing add-ons, merch), they should not get the block

## Dev Notes:

-  **Single source file:** `snippets/product.liquid`. The JSON-LD is emitted at ~line 914:

```
 // current code
<script type="application/ld+json">
{{ product | structured_data }}
</script>

```

-  **Proposed change** — add the supplemental block immediately after the existing one. Keep `{{ product | structured_data }}` exactly as-is:

```
// Example only - use product metafields and mapping from above table. AI Generated 

  <script type="application/ld+json">
    {{ product | structured_data }}
  </script>

  {%- liquid
    assign art_artist  = product.metafields.product.Artist
    assign art_medium  = product.metafields.product.art_medium
    assign art_form    = product.metafields.product.art_form
    assign art_surface = product.metafields.product.art_surface
    assign art_edition = product.metafields.product.art_edition
    assign art_series  = product.metafields.product.art_series
  -%}
  {%- if art_artist != blank or art_medium != blank or art_form != blank -%}
    <script type="application/ld+json">
      {
        "@context": "https://schema.org/",
        "@type": "VisualArtwork",
        "@id": {{ canonical_url | append: "#visualartwork" | json }},
        "name": {{ product.title | json }},
        "url": {{ canonical_url | json }},
        {%- if product.featured_image -%}
        "image": {{ product.featured_image | image_url: width: 1200 | prepend: "https:" | json }},
        {%- endif -%}
        {%- if product.description != blank -%}
        "description": {{ product.description | strip_html | strip_newlines | json }},
        {%- endif -%}
        {%- if art_artist != blank -%}
        "artist": { "@type": "Person", "name": {{ art_artist | json }} },
        {%- endif -%}
        {%- if art_medium != blank -%}
        "artMedium": {{ art_medium | json }},
        {%- endif -%}
        {%- if art_form != blank -%}
        "artform": {{ art_form | json }},
        {%- endif -%}
        {%- if art_surface != blank -%}
        "artworkSurface": {{ art_surface | json }},
        {%- endif -%}
        {%- if art_edition != blank -%}
        "artEdition": {{ art_edition | json }},
        {%- endif -%}
        {%- if art_series != blank -%}
        "isPartOf": { "@type": "CreativeWork", "name": {{ art_series | json }} },
        {%- endif -%}
        "mainEntityOfPage": {{ canonical_url | json }}
      }
    </script>
  {%- endif -%}

```
