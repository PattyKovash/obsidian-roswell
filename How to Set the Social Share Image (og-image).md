# How to Set the Social Share Image

This is the image shown when a product, collection, blog post, or page is shared as a link on Facebook, Slack, iMessage, etc.

## Default image (site-wide)

1. Shopify Admin → **Online Store → Themes → Customize**.
2. **Theme settings → Social media**.
3. Under **Sharing**, set **Default social share image**.

This image is used on any page that has no image of its own. Use a **1200×630px or larger** branded image (e.g. logo on a clean background) — smaller images will still work but won't be resized to the ideal share-preview size.

## Automatic per-page image (no setup needed)

If you don't set anything below, pages already use a sensible image automatically:
- **Products** → the product's featured (first) image
- **Collections** → the collection's image (if one is set)
- **Articles** → the article's image
- Everything else → the default image above

## Overriding the image for one specific page

To use a different image than the automatic one for a single product, collection, article, blog, or page:

1. Open that product/collection/article/blog/page in Shopify Admin.
2. Scroll to the **Metafields** section.
3. Find **Open Graph Image** and upload the image you want.
4. Save.

That image now overrides everything else for that page only. Leave it blank to go back to the automatic image.

> **Note:** if you don't see an "Open Graph Image" metafield field, it hasn't been set up for that content type yet — contact Roswell Studios to enable it.

## Image guidelines

- Recommended size: **1200×630px** (this is the standard size social platforms expect).
- Images smaller than that are shown at their real size — do not upload a small image and expect it to fill a large preview.
- Keep important content (logo, text) centered — some platforms crop the edges.
