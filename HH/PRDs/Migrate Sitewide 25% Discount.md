# Migrate Sitewide 25% Discount from Shopify Script to Discount Function

## Background:

The store currently uses a Shopify Script (Ruby) called **"12.01.25 - RS Discount Script - 25% Off Sitewide Sale"** to apply a flat 25% discount to all eligible products in the cart during sitewide sale events.

**Current Script Logic**

The existing Ruby script does the following:

1. Applies a 25% discount to all eligible line items.
2. Excludes products of type `"Gift Card"` from the discount.
3. If a discount code is present that does **not** begin with `LL-`, the discount is suppressed. `LL-` codes (generated by LoyaltyLion) are allowed to coexist.
4. Runs a separate `QuantityLimit` campaign that caps any product tagged `"Free Gift"` to a quantity of 1 per cart.

The Free Gift quantity limit (`QuantityLimit` campaign) that was bundled in the same script is **out of scope for this ticket** — it is being migrated in a separate ticket.

## Objective/Acceptance Criteria:

**Discount Function — Product Qualification**

- [ ] A Shopify Order Discount Function is created and deployed that applies 25% off to all eligible cart items.
- [ ] The function exposes the following configuration options for qualifying eligible products (via metafield or function configuration):
  - [ ] **`qualifyingCollection`** — a collection handle or ID. When set, only products belonging to this collection are eligible for the discount. Takes precedence over `qualifyingTags` if both are set.
  - [ ] **`qualifyingTags`** — one or more product tags. When set (and `qualifyingCollection` is not), only products with at least one of these tags are eligible.
  - [ ] **`excludedTags`** — one or more product tags that disqualify a product from the discount regardless of other qualifiers (e.g. `["gift card"]`). Tag matching is case-insensitive and whitespace-stripped.
- [ ] Products matching `excludedTags` are excluded from the discount even if they belong to the qualifying collection or carry a qualifying tag.
- [ ] If neither `qualifyingCollection` nor `qualifyingTags` is set, all products not matching `excludedTags` are eligible (replicates the current script behavior).

**Discount Function — Discount Logic**

- [ ] The function exposes the following configuration options for discount behavior (via metafield or function configuration):
  - [ ] **`discountType`** — type of discount to apply. Accepts `percent` or `fixed_amount`.
  - [ ] **`discountAmount`** — the discount value. For `percent`, `25` = 25% off. For `fixed_amount`, value in currency units.
  - [ ] **`discountMessage`** — the label shown on the discounted line item at checkout (e.g. `"25% OFF SITEWIDE SALE"`). 
  - [ ] **`enableDevTest`** — a dev mode flag. When enabled, the function triggers discount logic against a designated test product/condition. Reference implementation: [`enableDevTest` in delivery-po-box-validation](https://github.com/roswell-studios/BAUBLEBAR_CE_EXT/blob/release/_candidate/extensions/delivery-po-box-validation).
- [ ] All eligible line items receive the discount at the configured amount and type.
- [ ] No quantity or bundle threshold — every eligible item in the cart receives the discount.

**Discount Function — Discount Code Handling**
- [ ] If the sitewide discount gets applied, when a discount code beginning with `LL-` is present, the discount code is not removed.
- [ ] If the sitewide discount gets applied, when a discount code does NOT begin with `LL-` is present, remove the discount code.
- [ ] When no discount code is present, the sitewide discount applies normally if eligibility is met.

**General**
- [ ] The existing Shopify Script is unpublished/removed after the function is confirmed working.
- [ ] - Function is tested on a staging/dev environment before going live, using `enableDevTest` to verify discount and code rejection behavior.
- [ ] Edge cases covered: cart with only excluded products (no discount applied), cart with mix of excluded and eligible items (only eligible items discounted), `LL-` code present (discount applies), non-`LL-` code present (discount suppressed), no code present (discount applies).

**General Constraints**
- Shopify functions will not stack or combine with other automatic discounts or discount codes when they target the same line item. Native Shopify behavior is the best discount is applied.

**Not in Scope**
- Function UIs. Functions will be configured with GraphiQL app.
- Free Gift quantity limit (separate ticket: *Migrate Free Gift Quantity Limit*).
