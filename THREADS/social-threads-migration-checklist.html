Critical — customer-facing regressions

9 items

These change what a shopper sees or what data gets sent. Confirm and re-implement before launch.

layout/theme.liquid
missing

Two things dropped: the web_checkout cart-attribute fetch script, and the {% render 'beam-imports' %} call. The Beam snippet files still exist in the new theme, they're just no longer included anywhere, so Beam won't load at all until this is re-added.

blocks/_product-details.liquid
missing

The entire "recently viewed" view-counter script is gone, the fetches to qa.wpweb.co.in/social-threads/view-counter.php, the session tracking, the decrement-on-unload beacon. It was pointed at a qa. host with debug console.log calls left in, worth resolving ownership before re-adding.

missing

The entire Beam settings block is gone, including the API key that was present as a schema default. Not confirmed to be a security issue, some app keys are meant to be public-facing; needs a client conversation before deciding how to handle it. Whether this needs rebuilding at all also comes down to one question: is Beam being kept for the relaunch.

design system change

Needs a full visual pass through every page, not a settings-editor spot check.
