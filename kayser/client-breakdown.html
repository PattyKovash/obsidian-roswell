Consent & Tracking Plan

Both stores · Three options based on priority and budget

Why this matters for Triple Whale: TW’s Web Pixel is set to “Optimized” on both stores, meaning it respects Shopify’s consent framework. On NoNonsense, consent is never set (no banner) — so TW drops all conversion events for every new visitor. Enabling a proper consent banner directly fixes TW’s conversion tracking for every visitor who accepts.

On Hue, the banner hides the “Decline” button, so most visitors accept and TW fires correctly. The data looks accurate, but the consent is legally void.

Three Options

Get the consent banner live and fix pixel settings. Restores TW conversion data and covers all apps that use Shopify’s consent framework.
