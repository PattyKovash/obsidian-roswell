**The Problem:** True Classic Tees' Shopify site updates product pages instantly when you change colors, while most sites reload the entire page—slower and jarring UX.

  

**The Solution:** Instead of loading a new page per color, the code:

  

- Intercepts the color-swatch click before navigation

  

- Fetches only the data that changes (images, price, sections)

  

- Surgically updates those DOM elements

  

- Updates the URL without reloading
